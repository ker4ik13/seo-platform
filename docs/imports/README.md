# Импорт семантики и позиций

Каждый файл сначала проходит проверку безопасности. У CSV, TSV и XLSX затем
можно проверить распознанные колонки и подтвердить публикацию. Нативный проект
Key Collector получает готовое серверное сопоставление и после проверки
автоматически импортируется без таблицы предпросмотра.

## Доступные сейчас режимы

В интерфейсе доступны нативный проект Key Collector, универсальный файл и
импорт позиций. Профиль Топвизора временно отключён до завершения проверки
совместимости.

Обычный список запросов без файла добавляется кнопкой **Добавить** в
Семантике и не является режимом файлового импорта.

## Key Collector

Выберите режим **Key Collector** и загрузите нативный проект `.kc4`. Формат переносит:

- полное дерево активных групп, включая пустые группы;
- цвета, комментарии и доступные метатеги групп;
- запросы, их заметки из «Комментарий 1» и «Комментарий 2»;
- целевые и релевантные URL;
- базовую, точную и фиксированную частотность;
- текущие и исторические позиции Яндекса и Google, найденные URL и доступную
  сохранённую выдачу с заголовками и описаниями;
- релевантные страницы Яндекса и Google;
- остальные заполненные колонки как пользовательские поля.

После загрузки ничего сопоставлять и подтверждать не требуется: интерфейс
показывает разбор, проверку и публикацию, затем итоговые счётчики.

Корзина и удалённые группы Key Collector не импортируются. Комментарий самой группы сохраняется в пользовательской колонке `Key Collector · Комментарий группы` у её запросов.

Имя папки может содержать `/`: нативный импорт читает путь по `ParentId` и не
разбивает такое имя. Если вместо `.kc4` используется табличный экспорт,
выберите режим **Файл**, укажите путь группы одной колонкой, например
`Каталог/Холодильники/Встраиваемые`, и задайте его разделитель на шаге
сопоставления.

## Топвизор (временно недоступен в Web)

Выберите режим **Топвизор** и загрузите CSV, TSV или XLSX. Стандартные названия колонок сопоставляются автоматически. Перед проверкой можно изменить любое назначение. Неизвестные колонки не теряются: они предлагаются как пользовательские.

Пример: [`topvisor.csv`](../../frontend/public/examples/imports/topvisor.csv).

## Универсальная таблица

Первая строка должна содержать заголовки. Обязательна только колонка с запросом. Поддерживаются язык, приоритет, избранное, отслеживание, заметка, интент, путь группы, целевой URL, теги, частотности, позиции и пользовательские поля.

Пример: [`keywords.csv`](../../frontend/public/examples/imports/keywords.csv).

## Импорт позиций

Есть два формата.

### История по датам

Одна строка содержит запрос, необязательный `URL из выдачи`, а каждая колонка с датой — позицию на этот день. URL сохраняется как найденная страница для заполненных позиций этой строки, а не как целевой URL запроса. Пустая ячейка означает отсутствие замера. `-`, `–`, `—` и `0` означают, что позиция не найдена. Один файл относится к одному поисковику, городу и устройству; параметры выбираются перед проверкой.

Пример: [`positions-wide.csv`](../../frontend/public/examples/imports/positions-wide.csv).

### Построчный формат

Каждая строка содержит запрос, дату, поисковик, позицию и необязательный `URL из выдачи`. URL привязывается к этому снимку позиции, поэтому выгрузки внешних сервисов сохраняют найденную страницу отдельно от назначенного целевого URL.

Пример: [`positions-long.csv`](../../frontend/public/examples/imports/positions-long.csv).

Позиции можно обновить только у уже существующих запросов, выключив «Добавлять новые запросы». Если эту настройку включить, отсутствующие запросы сначала будут созданы.

## Кодировка и ограничения

- CSV и TSV: UTF-8 или Windows-1251.
- XLSX: один рабочий лист, без пароля.
- `.kc4`: нативный проект Key Collector, без шифрования.
- Большие файлы загружаются частями и могут безопасно продолжить обработку после временного разрыва связи.

Для CSV, TSV и XLSX перед публикацией проверьте сопоставление, число строк,
предупреждения и политику обработки существующих запросов.
