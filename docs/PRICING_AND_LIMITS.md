Годовая оплата соответствует десяти месячным платежам. Это стартовая гипотеза
цены для MVP, которую нужно проверять конверсией и удержанием, а не обещание
рыночного спроса. Подписка даёт редактор, ёмкость рабочей области и командную
работу; операции внешних SEO API оплачиваются отдельно. Пользователь не
платит за неиспользуемый обязательный пакет данных, а владелец не финансирует
непредсказуемые запросы из фиксированной абонентской платы. BYOK доступен
на всех тарифах, произвольных суточных лимитов на оплаченные данные нет.

Ориентиры модели: [Топвизор](https://topvisor.com/ru/pricing/) и
[Rush Analytics](https://www.rush-analytics.ru/pricing-plans) тарифицируют
инструменты/лимиты, а [Key Collector](https://www.key-collector.ru/pricing/)
использует лицензию на программу. SEOньорита должна продавать удобство
совместного редактора и рабочего процесса; заявление «самые дешёвые данные»
не используется.

Каталог публикуется как версия 5. Миграция не переводит существующие подписки
на новые цены или ограничения. Их автоматическое продление использует
исходную версию; API поддерживает явное продление своего старого тарифа.
При переходе неиспользованная стоимость переносится в дни нового плана.
Для той же версии/семейства плана досрочное продление сохраняет все оставшиеся дни.

Версия исполняемой модели: `2026-09-06@2`, Core `billing/provider-pricing.ts`.
Владелец подтвердил **50% маржи**. Денежные операции — целые копейки, внутренний
расчёт себестоимости — миллионные доли рубля. Floating point для списаний не используется.

## Формула

Цена = себестоимость / (1 − 50% − 4,5% − 6% − 2,5%).

4,5% — резерв на эквайринг; 6% — налоговый резерв; 2,5% — переменные риски.
Результат округляется вверх. Для базовой ставки карты 3,5% с НДС 22% от комиссии
расход составляет 4,27%, поэтому модель оставляет небольшой запас.
Источник: [тарифы ЮKassa](https://yookassa.ru/docs/support/payments/fees).

Это целевая маржа на оплачиваемый расход данных. Зарплата, маркетинг, сервер
и неиспользованная часть купленных у провайдера пакетов — отдельные расходы.
Наличие такой формулы не гарантирует чистую прибыль при любом числе клиентов.
Подписка оплачивает ёмкость платформы; внешние операции — баланс данных.
BYOK не списывает баланс данных платформы.

## Исходная стоимость

- XMLStock: обычный Live/Google/Wordstat — 25 ₽ за 1000 обращений;
  Yandex Search API — 28 ₽; Turbo — базовая стоимость плюс 10 ₽.
  Google/Live возвращает по 10 результатов, Search API — до 100.
  Для Turbo оценка консервативно учитывает до десяти страниц для Top-100.
  [Официальные тарифы XMLStock](https://xmlstock.com/?do=tariffs).
- Arsenkin: используем цену лимита Standard, округлённую вверх:
  2490 ₽ / 85 000 = 0,029295 ₽. Это не предполагает, что уже куплен Corporate
  или получена скидка. Для частотности — один лимит на вариант и ключ;
  для подбора Wordstat — два на исходную фразу; базовая кластеризация — 1,5.
  [Официальные тарифы Arsenkin](https://arsenkin.ru/tools/tariffs/all/).
- Для позиций Arsenkin Google Top-30/50/100 учитываются 2/3/5 лимитов,
  для Яндекса — 2; конкурентный Top-10 — 1.
  [Изменение стоимости проверок](https://help.arsenkin.ru/news/vaznye-izmeneniia-v-stoimosti-proverki-pozicii-google).
- В API кластеризации можно передавать четыре вида частотности. Модель
  резервирует по одному дополнительному лимиту за выбранный вид; точность
  тарификации опций нужно сверить с договором при активации системного аккаунта.
  [Параметры API кластеризации](https://help.arsenkin.ru/api/clustering-dev).

| Arsenkin Яндекс / Google Top-30, позиции | 160 ₽ |
| Arsenkin Google Top-50, позиции | 240 ₽ |
| Arsenkin Google Top-100, позиции | 400 ₽ |
| XMLStock, один вид частотности | 67,57 ₽ |
| Arsenkin, один вид частотности | 79,18 ₽ |

Rank сохраняет совместимость с существующим учётом: цена округляется за ключ,
потом умножается на размер задачи. Новые частотность/ИИ/кластеризация/research
округляются по нарастающему итогу фактически принятых units. Поэтому сумма
тысячи одиночных операций может отличаться от одной операции на тысячу ключей.
Цены хранятся в estimate, а не принимаются из браузера. Изменение параметров
или версии расчёта требует нового подтверждения.

## Резерв, отмена и сбои

1. Перед системной операцией пользователь видит провайдера, объём и максимальную сумму.
2. Core резервирует деньги атомарно; несколько параллельных задач не используют один остаток дважды.
3. Перед каждым платным обращением Core проверяет доступ. Jobs хранит отдельное короткое разрешение, без которого connector не может отметить START.
4. Принятый провайдером запрос учитывается один раз, в том числе если пользователь отменил задачу во время HTTP-вызова.
5. Неотправленная часть освобождается после окончания задачи. Истёкшие included credits не превращаются в новые credits после смены периода подписки.
6. Неопределённый submit сохраняется для разбора. Если task ID уже получен и сохранён, возобновляется polling, без повторного создания задачи у провайдера.

Системный режим включается после настройки настоящих аккаунтов и проверки
коммерческих условий. При rollout сначала выключить platform-paid флаги,
обновить Core и все Execution roles, проверить readiness и затем включить
нужного провайдера. Старый worker без ticket protocol не должен получать новые
системные задания. Откат флагов делается на совместимом новом artifact;
добавленные финансовые записи и enum values не удаляются.

У YooKassa гарантия идемпотентности длится 24 часа. Если ID созданной оплаты
или возврата не сохранён, после 20 часов повторный POST блокируется и нужна
сверка у провайдера. Известный объект продолжаем читать через GET; сбой сети
не является основанием создавать ещё одно списание.
[Гарантия идемпотентности YooKassa](https://yookassa.ru/developers/using-api/interaction-format).

Серверные ограничения провайдеров остаются реальными. Большие независимые
выборки должны выполняться очередью допустимых пакетов. Глобальную кластеризацию
нельзя незаметно разделять на независимые части с потерей связей между ними.

Для общего системного Arsenkin лимит кластеризации задаётся в Core:
`PLATFORM_ARSENKIN_CLUSTERING_KEYWORD_LIMIT=30000` по умолчанию (Standard).
Для 50k нужен Corporate и значение 70000; больше — подтверждённые условия
провайдера, технический потолок 300000. Проверка срабатывает до резерва денег.
Позиции и другие независимые измерения выполняются пакетами и не требуют
уменьшать размер всего проекта. [Ограничения аккаунтов Arsenkin](https://arsenkin.ru/tools/tariffs/all/).
