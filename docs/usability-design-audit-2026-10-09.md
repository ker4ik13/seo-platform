# Юзабилити и дизайн аудит SEOньориты

Дата: 9 октября 2026 года. Стенд: https://144.31.221.28:3000.

Запрошенные доработки форм, папок, URL-фильтров, календарей и матрицы позиций
реализованы локально. Доработки матрицы, больших деревьев, адаптивной админки,
общих контролов и чтения данных проведены через пользовательские пути.
Production не изменён; пуша нет. CI-код готов, подключение отдельного runner
для удалённого HTTPS job остаётся операторским шагом.

## Проверенные сценарии

49 маршрутов приложения, настроек, админки, публичного сайта и авторизации
проверены на ширинах 1440, 768, 390 и 320 px. Это 196 сочетаний маршрута и
ширины; старые проектные URL включены как переходы в их текущие экраны.
Проверены рабочие, пустые и ограниченные состояниями конфигурации экраны.
Регистрация, письма, реальные платежи и платные обращения к провайдерам в
этом обходе не запускались.

Отдельный HTTPS E2E использует 210 тестовых запросов, реальные импортированные
позиции и SERP, два дня и разные города. Ответы API и SQL не подменяются.
Проверка проходит UI → public API → Core/SEO → PostgreSQL → UI. Проверены
разворачивание дерева, новые фильтры, бесконечная загрузка, последовательные
номера, сохранение ширины, информация по наведению, сезонность и ручные даты
после reload. Hover не отправляет запросов к серверу.

SQL-проверка выполняется на отдельном PostgreSQL 18 после настоящих миграций.
Она проверяет старый и новый SERP, `www`, города, все четыре URL-сортировки,
границы cursor-страниц, согласованность матрицы и счётчиков и tenant isolation.
Тестовые данные публикуются owning import service, а не фиктивным ответом БД.

## Уже исправлено

- Поля форм больше не растягиваются из-за подсказки или ошибки соседа; input
  названия проекта и домена имеют одинаковые высоту и вертикальную позицию.
- Все обычные ветви дерева можно раскрыть или свернуть одним действием рядом
  с мультигруппой. Выбор папок и ключей не меняется.
- В семантике и позициях есть «Целевой URL задан / не задан» и четыре
  сортировки: URL А/Я, с целевой страницей / без неё сначала.
- Фильтр нескольких URL работает до pagination. Конкуренты и дубли одного
  адреса не считаются разными страницами; старый снимок не перекрывает новый.
  Saved views, массовый scope и экспорт передают то же условие.
- В новой сессии календаря обновляется только «ДО». Принятый вручную период
  не сбрасывается от reopen/reload/background refresh. «Сегодня» у поля «ДО»
  сохраняет «ОТ»; месяцы/недели сезонности остаются завершёнными периодами.
- У запроса на экране позиций есть доступная с клавиатуры информация:
  целевой и найденный URL, группа, время последнего замера. Она использует
  факты уже загруженной страницы. Сезонность открывается отдельной кнопкой
  и читает данные только по явному действию.
- Перед запросом добавлена колонка №. Нумерация непрерывная при загрузке
  следующих страниц; ширина меняется мышью/клавиатурой и сохраняется по
  пользователю и проекту.

## Выполненные задачи аудита

| Функция | Реализация и проверка |
|---|---|
| Матрица позиций и SERP | SQL OFFSET убран. Read window фиксирует серверный порядок opaque IDs, watermark, сводку и trend; cursor идёт от последнего ID. Кэш ограничен 32 MiB, 16 окнами и 120 секундами простоя; cold replica восстанавливает окно. Настоящий PostgreSQL проверяет все сортировки, отсутствие дублей и отсутствие полного пересчёта следующих страниц через pg_stat_statements. |
| Большая матрица в браузере | Общая fixed-height виртуализация. На 1 200 импортированных запросах DOM остаётся меньше 80 строк; последняя видимая нумерация — 1 200. Ширины, sticky-колонки, keyboard и lazy pagination сохранены. |
| Позиции на телефоне | Срез и период компактные, остальные условия раскрываются. Основное действие остаётся видно; удаление истории вынесено в «Ещё» с отдельным подтверждением. |
| Адаптивная админка | Intrinsic width grid/flex ограничен, действия переносятся. Собственный horizontal scroll остаётся у широких таблиц. Обход 320/390/768/1440 не допускает переполнения документа. |
| Читаемость | Позиции: запрос 13 px, прежняя компактная строка. Семантика: запрос возвращён к исходным 10 px по требованию пользователя; увеличение общей служебной шкалы не влияет на него. |
| Большие деревья | Виртуальное окно для длинного дерева. Источник selection/search/descendants — полная проекция, а не DOM. На 1 201 настоящей импортированной группе DOM ограничен; End переносит фокус на группу 1 200. |
| Единые URL-фильтры | Общий типизированный KeywordUrlFilters и chips для удаления применённых условий. Фильтрация остаётся серверной, до pagination; saved views и экспорт используют те же контракты. |
| Длинные селекты | Короткие selected labels, полный текст значения в title/доступном имени; adaptive trigger не расширяет страницу. |
| Колонки позиций | Только компактный список видимых дат, без формы ширин и плотности. Выбор дат сохраняется после reload; старый COMFORTABLE игнорируется. Строка 44 px, прежние ручки изменения ширины сохранены. |
| Календарь экспорта | Fixed-portal в native dialog, вне scroll-body. Открывается с учётом свободного места; на телефоне остаётся внутри viewport. Кнопка «Сегодня» центрирована, поля «ОТ/ДО» одинаковой высоты. |
| Выравнивание иконок и SERP | Кнопка создания группы использует штатный SVG 16×16. Общий close-action центрирован. Подсветка доменов — компактная переносимая строка, без длинного описания и пустых колонок. |
| Tooltip | Единый native button и portal, hover/focus/touch, Escape, viewport limits. Tooltip click не активирует checkbox родительского label. Оригинальные бренд-ассеты не изменены. |
| Группы запроса | После pagination одним SQL-запросом читаются до пяти путей и общий count. Quick info показывает остаток; hover не обращается к API. |
| Подтверждения | window.confirm убран из заметок, колонок, представлений, кластеров и пресетов. Общий component-owned dialog; безопасная кнопка получает фокус, закрытие/размонтирование не одобряет действие. |
| Журналы операций | Общий словарь stage/status используется Task Center, rank presentation и admin. Ожидание провайдера/его capacity отделено от сбоя; неизвестная техническая стадия не становится основным текстом. |
| Фоновое чтение | Pending GET объединяются по path и session identity, результаты не кэшируются. Отмена одного потребителя не отменяет остальных. Ошибка сети оставляет данные; 401/403/404 убирают недоступную проекцию. Offline HTTPS E2E подтверждает сохранение последней загруженной строки и корректный retry. |
| Prefetch настроек | Тяжёлый billing prefetch выключен. Реальный inventory проходит прямые маршруты; API/JS ошибки считаются ошибкой gate, а не успешной проверкой login page. |
| Пустые состояния | DataState различает пустую выборку, права, выключенную функцию, отсутствие подключения и recoverable error. CTA соответствует причине: очистить filters, изменить период, собрать данные, настроить подключение или retry. |
| Клавиатура | Стрелки/Home/End проходят virtual boundary; tree поддерживает collapse/expand и range selection. Native dialogs восстанавливают прежний фокус. |
| Контраст и focus | Основная палитра status/action скорректирована; обычный текст запроса измеряется по фактическим foreground/background, threshold 4.5:1. E2E требует видимый outline при focus. Это проверка указанных компонентов, не заявление о полной WCAG-сертификации. |
| Пресеты представлений | Позиции/Wordstat/ИИ/Работа с URL применяются явно, сохраняют filters, widths и custom columns. Колонки можно править и сохранять обычным view workflow. |
| Терминология и локализация | Source UI copy дополнена English translations, placeholder parity проверяется генератором; ранее существовавшие переводы сохранены. User names/queries/URLs не переводятся. Контекст остаётся конфигурацией, срез — географической идентичностью, группа — узлом дерева. |
| CI и real browser gates | Source CI включает types/lint/tests/schema/build/dictionary. Opt-in HTTPS job ограничен main и dedicated self-hosted test runner. Перед фактическим GitHub запуском нужен runner seo-platform-ui-test и environment test-stand; push/deploy в этой задаче не выполнялся. |

## Проверка выпуска

Штатная команда test-usability.sh создаёт изолированные test accounts,
публикует synthetic data настоящим owning importer пачками по 500 и читает
его через публичный HTTPS UI/API. API/SQL результаты не подменяются.
После проверки staff roles и сессии тестовых аккаунтов отзываются.
Числа сохранены в приватных runtime artifacts; токены не включаются в отчёт.

Матрица: 44 px в компактном режиме, запрос 13 px / weight 550, info target
24 px со SVG 13 px. Кнопка папок: SVG 16×16, отклонение центров 0 px.
Проверены формы, URL-фильтры, состояния tooltip/seasonality, storage/reload,
пагинация, большой DOM, клавиатура и настоящий offline refresh.

Сборка запускается штатным build-runtime.sh на остановленном стенде;
после start-runtime.sh проверяются status-runtime.sh и Caddy HTTPS.
Незавершённые платные очереди не запускаются автоматически во время визуальных
тестов. Новые импорты вынесены в отдельное предложение imports-design-proposal.md
и снимки макетов: их функционал и file/provider E2E ждут согласования.

## Основания и критерии

Внутреннее ТЗ требует keyboard/focus, самостоятельного scroll таблиц,
виртуализации больших выборок и читаемого текста. Для активных целей
WCAG 2.2 AA задаёт минимум 24×24 CSS px с оговорёнными исключениями по
размещению; внутренний touch-target проекта строже — 44 px.
[W3C Target Size](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html).

Для обычного текста ориентир контраста — 4.5:1, для крупного — 3:1; состояния
и исключения проверяются отдельно.
[W3C Contrast](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html).
Клавиатурный фокус должен оставаться различимым, включая поля и nested popups.
[W3C Focus Visible](https://www.w3.org/WAI/WCAG22/Understanding/focus-visible.html).

Кодовые основания: `frontend/components/rankings-workspace.tsx`,
`frontend/components/semantic-group-tree.tsx`, `frontend/components/info-tooltip.tsx`,
`frontend/components/semantic-keyword-inspector.tsx`,
`frontend/components/project-notes.tsx`, `frontend/app/admin/admin.css`,
`backend-core/modules/seo/src/rank-workbench/rank-workbench.service.ts`.
Артефакты обхода сохраняются вне Git в приватном runtime tmp; отчёт не
публикует cookies, ключи, персональные сведения или тексты рабочих проектов.
