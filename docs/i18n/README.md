# Русский и английский интерфейс

Язык интерфейса (`ru` / `en`) хранится в `User.locale`; гостевой выбор — в cookie
`seo_ui_locale`. Не путать его с языком ключей, проекта или рабочей области.
Авторские названия, ключи, заметки, описания URL и пользовательские значения
не проходят через словарь. Не переводить весь DOM и не применять `t` к `.name`
или `.text` произвольной пользовательской записи.

Для подписей и статусов использовать `<UiText text="Сохранить" />` или
`const { t, locale } = useUiLocale()`. Атрибуты `title`, `aria-label`, placeholder
принимают `t(...)`. Форматтеры получают `locale` явно, с одинаковым значением на
сервере и в браузере. Новые строки с пользовательскими значениями оформлять
`<UiText text="Проект «{0}»" values={[project.name]} />`: значения вставляются
как текст, не переводятся и не интерпретируются как HTML.

Новые пары RU → EN добавлять в `en-extra.json`. Первичный каталог находится в
`ui-catalog.json`, дополнительные старые UI helpers — в `dynamic-catalog.json`.
Числовые индексы их translation chunks стабильны. `null` означает просмотренный
пример кода или доменную константу, которую не следует переводить.

```bash
node infrastructure/i18n/build-dictionary.mjs
node infrastructure/i18n/build-dictionary.mjs --check
pnpm --filter @seo-platform/frontend test
```

`ui-translations.ts` — сгенерированный файл. Не редактировать его напрямую.
Для legacy UI helpers, возвращающих уже собранную строку, словарь умеет
распознавать известный шаблон за ограниченное линейное время; новое приложение
должно передавать значения явно. Вложенные имена/ключи при этом не переводятся.

`localize-ui.mjs`, `localize-dynamic-ui.mjs`, `localize-formats.mjs` — одноразовые
помощники выполненной миграции, сохранённые для review. **Не запускать повторно**:
они преобразуют исходники и не являются повседневными генераторами. Им требовался
локальный TypeScript AST toolchain; это не production dependency.

При UI проверке: RU и EN, перезагрузка и новая сессия, desktop/mobile, поиск в
select по переведённой подписи, одинаковые option values, сохранность авторского
контента, сообщения permission/loading/error и числа/даты в текущей локали.
