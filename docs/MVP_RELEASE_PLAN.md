# Релиз MVP: решения владельца и исполнение

Обновлено 8 сентября 2026. Целевой срок: выходные 12–13 сентября 2026.
Это зафиксированные ответы владельца; они приоритетнее старых предположений
roadmap и аудита о составе MVP.

## Принятые решения

- Бренд SEOньорита, основной домен `seonorita.ru`; домен задаётся конфигурацией.
- Владелец — самозанятый на НПД в России; сервер в Германии. ФИО пока не
  публиковать. Контакт поддержки: https://t.me/ker4ik13.
- Главный администратор: `kireev.kirill2004@mail.ru`, дополнительных staff нет.
- Русский и английский интерфейс обязательны, включая платежи и основные SEO flows.
- Приём рублёвых платежей для России через YooKassa и adapter Crypto Pay.
  Боевой магазин YooKassa ещё не оформлен. Существующие тестовые credentials
  искать в уже настроенной конфигурации без вывода секретов.
- XMLStock и Arsenkin под системными ключами должны иметь функциональный
  паритет с доступными BYOK-операциями: позиции/конкуренты, частотность,
  Wordstat expansion, ИИ-выдача и кластеризация там, где provider их поддерживает.
- Цель — примерно 50% маржи после переменной себестоимости, не 50% наценки.
  Чистая прибыль не гарантируется: фиксированные расходы и фактическая
  загрузка provider subscription учитываются отдельно.
- Подписка оплачивает platform capacity. Внешние платные операции используют
  предварительный расчёт, резерв и списание по фактическому принятому результату.
  Произвольных суточных лимитов пользователю не вводить; balance, worker
  capacity, provider rate limits и проверяемая себестоимость остаются защитой.
- Оповещать владельца в Telegram, когда остаток provider account ниже 500 ₽.
  Для Arsenkin отображать лимиты и их денежную оценку с явно заданной ценой лимита.
- Тарифную сетку и условия изменения подписки разработать в рамках этих принципов.
  Возвраты решает владелец; обычная политика — неиспользованные оплаченные
  дни и остаток оплаченного data balance с учётом применимых обязательных прав.
- Автоматическая выдача чеков пока выключена; подготовить adapter «Мой налог»
  по рабочей реализации соседнего `neuroluv-server`, с отдельным feature flag.
- SMTP в production уже работает; переиспользовать существующий канал.
- Дополнительно нужен вход через Telegram-бота, доступный только при полной env-конфигурации.
- Яндекс Метрику подключить позднее. Сейчас — собственная полезная admin analytics,
  рабочие административные действия, состояние провайдеров и готовность релиза.
- Ожидается до 300 пользователей, около 10 одновременно активных. Контрольная
  нагрузка — 50 000 keywords в проекте с проверкой роста сверх этого размера.
- Бюджет текущего сервера — $50/месяц. Production уже развёрнут в Dokploy
  из monorepo/Compose. Существующие production данные сохраняются полностью.
- S3/backup уже настроены в Dokploy; их существование и восстановление проверить.
- Реальные SEO canary: **не более пяти оплачиваемых provider requests суммарно**,
  аккаунт владельца/проект «Нейролюб». Не путать пять keywords с пятью вызовами:
  глубина SERP, frequency variants и дополнительные страницы могут увеличить расход.

## Внешние зависимости

- Боевой YooKassa shop появится позднее; не имитировать боевой checkout до него.
- Не переносить webhook/token соседнего приложения на другой URL: отдельное
  приложение Crypto Pay/Telegram или безопасная маршрутизация обязательны.
- Подтверждённые коммерческие условия provider system keys ещё не предоставлены.
  Реализацию подготовить; доступность production activation отразить явно.
- ФИО/обязательные данные оператора пока не публикуются по требованию владельца;
  документы являются подготовленными текстами, а не подтверждением полной
  юридической готовности анонимного checkout.
- Налоговые и платёжные ограничения проверить по актуальным официальным источникам.

## Проверки

Настройки проверены в браузере через HTTPS Caddy на четырёх ширинах (11
сквозных сценариев, 80 скриншотов). Отдельно прошли переключение и сохранение
RU/EN, защита пользовательских названий, публичные документы/тарифы в 32
сочетаниях маршрута и viewport. Эти проверки относятся к сборке до последних
изменений больших rank operations, финансового разбора и писем.

В настоящем изолированном PostgreSQL проверены деньги/гонки, Telegram, NPD,
платёжная идемпотентность, provider tickets. Тест 50k полностью записывает
результаты и финализирует запуск; реальные провайдеры заменены controlled
responses. Последние pin/notice/bootstrap/balance изменения прошли полный PostgreSQL
прогон `e2e.pgMdjceYdQ`; восстановление и обновление четырёх свежих backup —
`e2e.restore.PPfZ2Gez`. Итоговый отчёт: `mvp-production-audit-2026-09-07.md`.
**Живая проверка: 3 платные операции, 5 HTTP-запросов всего из общего предела 5. XMLStock и Arsenkin вернули частотность 61; XMLStock также вернул Топ-10 с neuroluv.ru на позиции 1.**
Проверены настоящие production connectors на BYOK владельца; этот canary
не создавал Jobs в приложении. Полный Job/ledger workflow проверен отдельно
на реальных PostgreSQL/HTTP с controlled provider responses.
Артефакт: runtime/tmp/e2e.mvp-release-20260906/live-provider-report.json.

Production Compose настроен на `main`, `infrastructure/compose.dokploy.yml` и
автоматический deploy. Все новые SQL migrations просмотрены: они добавляют
таблицы/колонки/индексы либо расширяют constraints; пользовательские строки не
удаляются. Версии тарифов сохраняются, новая сетка закрывает только период
действия прежней версии. Перед migration release обязателен настроенный
логический backup четырёх PostgreSQL database.
Исходный аудит — `mvp-audit-2026-09-06.md`; актуальные внешние условия и
инженерная приёмка — `MVP_LAUNCH_CHECKLIST.md`.
