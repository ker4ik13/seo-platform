# Product application

Пользовательское приложение SEO-команд. Next.js App Router, порт `3001`.

Foundation-экран демонстрирует дизайн-систему, адаптивную оболочку и явный
degraded state при недоступном Platform API. Данные на экране пока
демонстрационные; подключение начинается с vertical slice auth/workspace/project.
