# Operations admin

Внутренняя административная панель приложения, Next.js App Router, порт `3002`.
Она не заменяет Directus: здесь будут аккаунты, workspace, проекты, очереди,
лимиты, интеграции, feature flags и аудит. Любые mutation-операции появятся
только вместе с отдельными admin permissions и повторной аутентификацией.
