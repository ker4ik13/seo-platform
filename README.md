# Marketing website

Публичный Next.js-сайт, порт `3000`. Локали `ru` и `en` заложены с первого
инкремента. Контент читается из коллекции Directus `marketing_pages`; при
недоступной CMS используется типизированный fallback, поэтому сайт остаётся
доступным. Directus управляет публичным контентом и метаданными, но не данными
приложения.
