# SemaFlow — дизайн-прототип SEO-платформы

Интерактивный статический прототип SaaS для SEO-команд.

## Просмотр

```bash
python3 -m http.server 8877
```

Открыть `http://localhost:8877/`.

## Основные экраны

- `#dashboard` — настраиваемый дашборд проекта;
- `#semantics` — семантическое ядро и кластеры;
- `#positions` — история и динамика позиций;
- `#parsing` — Wordstat, SERP и другие сборщики;
- `#integrations` — API-подключения, здоровье и расходы;
- `#automations` — расписания и триггеры;
- `#notes` — текстовая база знаний проекта.

Дополнительно заложены конкуренты, карта страниц, команда и настройки проекта.

## Интерактивность

- переключение разделов без перезагрузки;
- меню проектов;
- выбор строк ядра и массовая панель операций;
- модальные окна запуска сбора, интеграций и расписаний;
- очередь фоновых задач;
- демонстрационные уведомления;
- адаптивная боковая навигация.

Название SemaFlow и все показатели демонстрационные.
